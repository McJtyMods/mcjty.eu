# AGENTS.md

Guide for coding agents working on mcjty.eu: McJty's Minecraft modding
tutorials, mod documentation, and In Control rule validator.

## Layout

pnpm workspace with two packages:

| Path          | Package                     | What it is                                              |
| ------------- | --------------------------- | ------------------------------------------------------- |
| `www/`        | `@mcjty-website/www`        | Docusaurus 3.10 site. Deployed to GitHub Pages.         |
| `redirector/` | `@mcjty-website/redirector` | Cloudflare Pages project that redirects old wiki URLs.  |

Key files in `www/`:

```
docusaurus.config.ts     Site config: navbar, footer, metadata, plugins
sidebars.ts              Sidebars "docs" (tutorials) and "mods", both autogenerated
sidebars-apps.ts         Sidebar for the separate "apps" docs plugin
tailwind.config.ts       Tailwind 3 config (preflight disabled)
docs/                    Tutorials by Minecraft version, plus docs/mods/
apps/                    Android app docs, served at /apps
src/pages/index.tsx      Homepage
src/pages/control-validator/  Validator page
src/components/ControlValidator/  Validator UI, Zod schemas, JSON parser
src/components/AdBanner/ AdSense banner, injected on every page
src/theme/Layout/        Swizzled wrapper that adds AdBanner above content
src/data/mods.ts         Static mod list rendered on the homepage
src/css/custom.css       Global styles, brand palette, Infima overrides
scripts/validate-incontrol-docs.mjs  Checks JSON examples in In Control docs
static/                  Images, favicons, CNAME, ads.txt
```

## Toolchain

- Node 26 (`.nvmrc` is `v26`). `engineStrict` is on, so older Node fails install.
- pnpm 10.33.0, pinned by `packageManager`. Run `pnpm install` at the root.
- Biome for lint and format. No ESLint or Prettier.
- Knip for unused files, exports, and dependencies. Config is `knip.jsonc`.
- TypeScript 6. Do not upgrade to 7: `@docusaurus/tsconfig` sets `baseUrl`,
  which TypeScript 7 rejects.
- Tailwind 3. Tailwind 4 needs a different PostCSS plugin and CSS-based config.

## Commands

Run from the repo root unless noted.

```bash
pnpm install                                   # install everything
pnpm www dev                                   # dev server with hot reload
pnpm www build                                 # production build into www/build
pnpm www start                                 # serve the production build
pnpm www typecheck                             # tsc against tsconfig.typecheck.json
pnpm www validate:incontrol-docs               # parse every titled JSON example
pnpm lint                                      # biome check
pnpm lint:fix                                  # biome check with fixes, including unsafe
pnpm lint:errors                               # errors only
pnpm lint:ci                                   # what CI runs
pnpm unused                                    # knip --cache
```

Before finishing a change, run `pnpm lint`, `pnpm www typecheck`,
`pnpm unused`, and `pnpm www build`. The build reports broken links as warnings, so read its output.
Run `pnpm www validate:incontrol-docs` after editing In Control docs.

## CI and deployment

`.github/workflows/ci.yaml` runs on every PR and push to `main`. It uses two
composite actions:

- `.github/actions/setup` installs pnpm, Node from `.nvmrc`, and dependencies.
- `.github/actions/checks` runs `lint:ci`, the www typecheck, and `unused`.

The `checks` job runs first, then `build`. Pushes to `main` deploy `www/build`
to GitHub Pages. Third-party actions are pinned to commit SHAs with a version
comment. Add new steps to the composite actions, not to each job. The custom
domain comes from `www/static/CNAME`.

The redirector deploys separately to Cloudflare Pages. Its `deploy` script runs
`wrangler deploy`, which is the Workers command and fails for this Pages
project. Use `wrangler pages deploy public` instead.

## Code style

- Biome enforces formatting: two-space indent, double quotes, 80 columns.
- Tailwind classes must be sorted. Biome reports unsorted classes as errors,
  and `pnpm lint:fix` sorts them.
- React components are typed as `React.FC`. Pages use `@theme/Layout`.
- Use `@site/...` imports for files under `www/`.
- Prefer CSS modules for page styles and `custom.css` for global rules.
  Tailwind utilities are fine for small layout tweaks.
- The `img` lint warning on the homepage comes from a Next.js rule. It does not
  apply to Docusaurus, so ignore it.

## Styling notes

- Colours come from CSS variables in `src/css/custom.css`. Use
  `--ifm-color-primary*` for accents and the `--mcjty-*` tokens for surfaces,
  borders, muted text, and tags. Every token is redefined under
  `[data-theme="dark"]`, so check both themes.
- `--ifm-background-color` is set explicitly. Without it the page background
  is transparent, and a dark OS setting shows through in light mode.
- Tailwind preflight is off so Infima's base styles survive. The `container`
  utility is blocklisted because Infima already defines `.container`.
- Infima's `.tabs--block` stacks vertically below 996px. The validator uses its
  own `.validator-tab*` classes for this reason.
- Navbar social links are `type: "html"` items built by `iconLink()` in
  `docusaurus.config.ts`. They show icons on desktop and labels in the mobile
  menu.
- The mobile breakpoint is 996px, matching Infima.

## Docs content

- 131 Markdown files and no MDX. Keep it that way unless a page needs
  components.
- Sidebars are generated from folders. Order comes from `sidebar_position`
  frontmatter. The only other frontmatter key in use is `title`.
- A folder's main page shares its name, for example
  `docs/1.19/1.19.md` serves `/docs/1.19`.
- `docs/1.21.1_26.2/_category_.json` is the only category file. It sets the
  label and links the category to its index doc.
- Most images are hosted on imgur. Local images live in `docs/assets/`.
- In Control examples in `docs/mods/control-mods/control-mods-20*.md` that use
  a fenced `json` block with `title=` must be complete, valid files. The
  validate script parses them.
- Renaming or moving a doc changes its URL. Update internal links, the footer
  in `docusaurus.config.ts`, the homepage cards, and the redirector maps.

## Homepage

`src/pages/index.tsx` renders a hero, quick-link cards, an about section, a
mod grid, and a callout. The mod grid reads `src/data/mods.ts`. To add a mod,
add an entry there with `category`, `description`, and optional `docs` route
and `curseforge` slug. Do not fetch mod data at runtime. The earlier cfwidget
integration broke when that service went down.

## Control validator

- `data.ts` maps each Minecraft version to Zod schemas per rule file
  (`spawn`, `spawner`, `phases`).
- `schemas.ts` holds the schemas. `jsonParser.ts` is a custom parser that
  reports duplicate keys, which `JSON.parse` would silently drop.
- `utils.ts` turns Zod issues into messages. Messages starting with
  `Warning:` render as warnings. All others render as errors.
- To support a new version, add schemas and a `DATA` entry, then test the page
  with valid and invalid files.

## Redirector

- `redirector/public/_redirects` sends `/` to `https://mcjty.eu/`.
- `redirector/functions/[[path]].js` maps old wiki page names to new doc URLs
  with 301 redirects. Add entries there when doc URLs change.
- Check it compiles with `pnpm --filter @mcjty-website/redirector exec
  wrangler pages functions build`.

## Ads and analytics

- The AdSense script loads globally from `docusaurus.config.ts`. `AdBanner`
  renders only when given a numeric slot, and it hides itself when unfilled.
- The Vercel analytics plugin is enabled, but the site is hosted on GitHub
  Pages. Its script returns 404 in production, which is harmless.

## Knip

- Swizzled components in `www/src/theme/` and `www/scripts/*.mjs` are listed as
  entries because nothing imports them.
- Redirector entries are `functions/**`, which Cloudflare routes by path.
- Knip's Docusaurus plugin resolves plugins by package name. Use full names
  such as `@docusaurus/plugin-vercel-analytics` in `docusaurus.config.ts`.
- Remove unused exports rather than ignoring them.

## Things to avoid

- Committing `www/build` or `www/.docusaurus`. Both are gitignored.
- Upgrading TypeScript to 7 or Tailwind to 4 without a planned migration.
- Adding runtime fetches to third-party APIs on the homepage.
- Editing generated sidebars by hand. Change frontmatter or folders instead.
